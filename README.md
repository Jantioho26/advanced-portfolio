# Advanced Portfolio — Frontend Development

A personal portfolio website created during my frontend development course to practice HTML, CSS, JavaScript, and responsive web design.

**Live Demo:** https://jantioho26.github.io/advanced-portfolio/

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages — Deployment

## Features

- **About Me Section:** Introduces my background, skills, and interest in frontend development.
- **Project Showcase:** Displays featured projects with descriptions and technologies.
- **Contact Form:** Interactive form with name, email, and message fields.
- **Navigation:** Easy navigation between the About, Projects, and Contact sections.
- **Responsive Layout:** Designed to provide a user-friendly experience across different screen sizes.

## How to Run Locally

1. Clone the GitHub repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the VS Code Live Server extension.

## Deployment

Deployed using GitHub Pages.
